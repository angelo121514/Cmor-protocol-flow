# Inventario de fuentes

El código público se organiza en `src/` (frontend), `shared/` (contratos), `supabase/functions/` (servidor), `supabase/migrations/` (esquema), `scripts/` (herramientas) y `services/image-inspector/` (antivirus).

Los manifiestos y hashes de despliegues privados fueron excluidos. `npm run check:public` revisa los archivos versionados de esta distribución y `npm run test:docs` verifica enlaces locales.
